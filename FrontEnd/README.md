# Naqsh Portfolio - Frontend

This is the frontend repository for my personal portfolio, built to showcase my web development projects and skills as a Full-Stack Developer.

## 🚀 Tech Stack

- **React** with **Vite** for incredibly fast development and builds.
- **Tailwind CSS** for modern, responsive, and beautiful utility-first styling.
- **Redux Toolkit** and **RTK Query** for state management and seamless API data fetching.
- **React Router** for client-side routing.
- **React Icons** for crisp SVG vector icons.

## ✨ Features

- **Modern UI/UX**: Aesthetic design with a dark mode base, neon-green accents, glowing hover effects, and smooth animations.
- **Dynamic Projects Showcase**: Fetches and displays portfolio projects directly from the backend database.
- **Admin Dashboard**: A secure portal for me to add, edit, or delete projects in real-time. Includes image uploading straight to Cloudinary.
- **Responsive Layout**: Designed to look great on mobile phones, tablets, and desktop screens.
- **Smart API Detection**: Uses a centralized `apiConfig.js` to intelligently switch between local variables and Vercel's production variables smoothly.

## 📦 Getting Started

1. **Clone the repo**
2. **Install dependencies**: `npm install`
3. **Start development server**: `npm run dev`
